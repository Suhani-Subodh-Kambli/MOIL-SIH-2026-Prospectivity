# MOIL SIH Full-Stack Prototype

## Architecture

React + Vite
→ Express API
→ MongoDB (optional local/Atlas)
→ existing XGBoost exploration outputs
→ Python Random Forest production-shortfall baseline

## Start backend

```powershell
cd server
npm install
copy .env.example .env
npm run dev
```

MongoDB is optional for the first demo. Without MongoDB the API uses an in-memory user store and JWT auth.

## Start frontend

```powershell
cd client
npm install
npm run dev
```

Open the Vite URL shown in the terminal.

## Production shortfall

The backend invokes `production_shortfall/predict.py`.

For the demo it uses deterministic synthetic operational data. For a real model, put verified mine-level records in:

`data/production/production_history.csv`

The model expects the features documented in `data/production/README.md`.

## Exploration

The API automatically serves:

`outputs/indiawide/detailed_zone_targets.geojson`

and

`outputs/indiawide/detailed_zone_target_zones.csv`

generated by the existing ML pipeline.

Keep `outputs/` ignored by Git; generated prediction artifacts should not be committed.
